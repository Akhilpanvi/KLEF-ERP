Terms

Click a student to see their courses. "Left" = classes each course is still expected to hold until the last instruction day, estimated from the academic calendar (Sundays, holidays and exam weeks excluded) and how often the course has met on each weekday. "Out of reach" = courses that stay below the target even if every remaining class is attended. Data is as of each student's last fetch.
